## intro — existing narration retained

Viewing Workflow   Learning outcome:  Use the viewing system methodically and make a documented, accountable decision.  This activity explains viewing workflow. Use the viewing system methodically and make a documented, accountable decision. Select each panel to work through the approved practice. 

## summary — awaiting narration

1. Confirm readiness: check the server connection, Viewer ID, minimum viewing time and approved defaults. Only the Supervisor configures the station.

2. Begin in Normal with F1. Examine the whole image before concentrating on details.

3. Navigate systematically with zoom, pan or Auto-Pan. Avoid random searching.

4. Enhance doubtful areas using brightness, contrast, different viewing modes and more than one zoom level.

5. Compare a previous image of the same person with F5 where available. Consider whether the object is new, previously visible, changed, or part of the person.

6. Record the finding with factual annotations and comments. Record observations rather than unsupported conclusions.

7. Make the authorised release-or-hold decision after completing the examination. The Movement Log preserves the modes, zooms, pans and adjustments used.

If the result remains unclear or configuration is needed, escalate to the Supervisor through the approved process rather than improvising.

Key takeaway: A defensible decision combines methodical examination, factual recording and appropriate escalation.

## state-01 — existing narration retained

Step 1: Confirm Readiness. Before viewing begins, confirm that the station is correctly connected and ready:
Correct server connection;
Correct Viewer ID;
Minimum viewing time configured;
Appropriate saved palette and default settings. Only a Supervisor may configure the station. 

Key takeaway: The Viewer confirms readiness; the Supervisor controls configuration. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-02 — existing narration retained

Step 2: Begin with Normal View. Press F1 to begin with the Normal image. Examine the full image systematically before concentrating on a particular area. Establishing a baseline helps the Viewer understand where an object sits in relation to the rest of the body. 

Key takeaway: Start with the whole image before examining the detail. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-03 — existing narration retained

Step 3: Navigate Systematically. Use zoom, pan or Auto-Pan to move methodically across the image. Do not jump randomly between isolated areas. Systematic examination reduces the chance of overlooking a small, low-contrast object. 

Key takeaway: Methodical viewing is more reliable than random searching. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-04 — existing narration retained

Step 4: Enhance Doubtful Areas. If an area appears unusual: Adjust brightness and contrast; Examine it at more than one zoom level; Compare Normal, Un-sharp Mask, Emboss, High Contrast and Invert Colours. No single mode is best for every object. 

Key takeaway: Never judge a doubtful area from only one mode or one zoom level. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-05 — existing narration retained

Step 5: Compare the Reference Image. Use F5 to retrieve a previous image of the same person, where available. Ask: Is the object new?
Was it visible before?
Has its position or appearance changed?
Could it be part of the person rather than a concealed object?

Key takeaway: Comparison adds context to what the Viewer sees today. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-06 — existing narration retained

Step 6: Record the Finding. Annotate the area and add a concise, factual comment where necessary. Record what was observed without speculation or accusatory language. The annotation should help an authorised Reviewer understand the concern. 

Key takeaway: Record the observation—not an unsupported conclusion. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-07 — existing narration retained

Step 7: Make and Preserve the Decision. After completing the examination, make the authorised decision:
Release: No suspicious object requires further action.
Hold: Further action or a search is required. The Movement Log preserves the sequence of modes, zooms, pans and adjustments used during the examination. 

Key takeaway: A defensible decision is based on disciplined viewing and a traceable record. Why this matters: Use the viewing system methodically and make a documented, accountable decision.
