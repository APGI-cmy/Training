## summary — awaiting narration

ADD means Automatic Diamond Detection. It flags possible objects for the Viewer’s attention; it does not replace human judgement.

Emboss makes edges and textures appear raised or recessed. Un-sharp Mask sharpens detail and emphasises edges.

An IP Address connects the viewing station to the image server. IVS means Image Viewing System: the software used to examine and process Scannex images.

A palette assigns colours or grey shades to X-ray densities. Changing it changes the display, not the underlying scan data.

A reference image is a previous image of the same person. Where one exists, F5 supports comparison between an object already present and a newly introduced object. It adds context; the Viewer still makes the decision.

Key takeaway: Use the correct term and understand what each control changes.

## state-07 — existing narration retained

Reference Image. Pressing F5 calls up a previous image of the same person, if one exists. Comparing the current scan with a reference image can help the Viewer determine whether a suspicious shape: Has appeared since the earlier scan; Was already present; May be part of the person, such as a medical implant or healed injury. The Reference Image supports judgement; it does not make the decision for the Viewer. 

Key takeaway: A new object may be significant. A familiar object may have an innocent explanation. Why this matters: Use the viewing system methodically and make a documented, accountable decision.
