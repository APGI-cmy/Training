## state-01 — awaiting narration

Viewing System Glossary. ADD means Automatic Diamond Detection. It flags possible objects for the Viewer’s attention; it does not replace human judgement.

Emboss makes edges and textures appear raised or recessed. Un-sharp Mask sharpens detail and emphasises edges.

An IP Address connects the viewing station to the image server. IVS means Image Viewing System: the software used to examine and process Scannex images.

A palette assigns colours or grey shades to X-ray densities. Changing it changes the display, not the underlying scan data.

A reference image is a previous image of the same person. Where one exists, F5 supports comparison between an object already present and a newly introduced object. It adds context; the Viewer still makes the decision.

Key takeaway: Use the correct term and understand what each control changes. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-02 — awaiting narration

Viewing Controls and Image Enhancement. The Viewing System provides different ways to examine the same X-ray data. Viewing modes, palette, brightness, contrast and zoom change its appearance; they do not change the original scan data.

With the mouse, the left button adjusts brightness, the right adjusts contrast and the middle toggles Toolbar and Pan modes. Left and right together switch the saved palette and Auto Palette. Report an incorrectly configured saved palette to the Supervisor.

F1 returns to Normal. F2 selects Un-sharp Mask, F3 Emboss and F4 High Contrast. F5 switches the reference image on or off, F6 inverts colours, F7 zooms out and F8 zooms in. F10 opens Review login and F11 Overview login.

Escape switches Toolbar and Pan modes. Arrow keys pan in Toolbar mode. Space starts Auto-Pan and Shift+Space reverses or controls it. The / and * keys change contrast; + and − change brightness.

Move between a whole-image overview and finer detail using zoom, pan and Auto-Pan. Compare doubtful areas in more than one mode and zoom level. Use a previous image of the same person when one is available.

Annotate and comment factually where appropriate. Use authorised export, TIFF loading and print functions to preserve the examination. The Viewer does not change station configuration.

Key takeaway: Examine systematically, compare views and preserve a traceable decision. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-03 — awaiting narration

Viewing Workflow. 1. Confirm readiness: check the server connection, Viewer ID, minimum viewing time and approved defaults. Only the Supervisor configures the station.

2. Begin in Normal with F1. Examine the whole image before concentrating on details.

3. Navigate systematically with zoom, pan or Auto-Pan. Avoid random searching.

4. Enhance doubtful areas using brightness, contrast, different viewing modes and more than one zoom level.

5. Compare a previous image of the same person with F5 where available. Consider whether the object is new, previously visible, changed, or part of the person.

6. Record the finding with factual annotations and comments. Record observations rather than unsupported conclusions.

7. Make the authorised release-or-hold decision after completing the examination. The Movement Log preserves the modes, zooms, pans and adjustments used.

If the result remains unclear or configuration is needed, escalate to the Supervisor through the approved process rather than improvising.

Key takeaway: A defensible decision combines methodical examination, factual recording and appropriate escalation. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-04 — awaiting narration

Roles, Permissions and Accountability. The Viewer independently examines images, uses approved enhancement and comparison tools, records observations and makes the authorised release-or-hold decision. The Viewer does not configure the station. The Viewer remains separate from the Scan Operator and does not meet the person being scanned; this protects impartial interpretation and prevents one person controlling both scanning and image interpretation.

Only the Supervisor configures the IVServer IP address, Viewer ID, minimum viewing time, Auto Release Time and saved defaults. IDs 1–4 are normal Viewers; IDs 9–16 are Review and Overview stations. Minimum View Time is 10–120 seconds. Auto Release Time is normally 0 (off) and is used only for testing.

Review, accessed through F10, re-examines images after the original decision for authorised quality assurance and investigation. The Database Editor is available only in Review mode.

Overview, accessed through F11, allows authorised quality-control personnel to observe a connected Viewer’s live work.

The Movement Log records and replays mode changes, zooms, pans, brightness and contrast adjustments. It makes the examination and decision traceable.

Key takeaway: Keep roles separate, configuration controlled and the examination accountable. Why this matters: Use the viewing system methodically and make a documented, accountable decision.
