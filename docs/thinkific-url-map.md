# Thinkific URL Map

This branch provides stable, Thinkific-ready URLs for VPSHR Level 0 HTML packages.

Use your `urls-module` Vercel production domain as the base:

`https://<your-urls-project>.vercel.app`

## Notes

- Canonical Thinkific URLs use the `unitN` pattern above.
- Legacy `luN` URLs still resolve and redirect to canonical `unitN` routes.
- Each route renders a minimal wrapper and iframe around the published HTML package.
