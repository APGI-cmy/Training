## summary — awaiting narration

The Viewer independently examines images, uses approved enhancement and comparison tools, records observations and makes the authorised release-or-hold decision. The Viewer does not configure the station. The Viewer remains separate from the Scan Operator and does not meet the person being scanned; this protects impartial interpretation and prevents one person controlling both scanning and image interpretation.

Only the Supervisor configures the IVServer IP address, Viewer ID, minimum viewing time, Auto Release Time and saved defaults. IDs 1–4 are normal Viewers; IDs 9–16 are Review and Overview stations. Minimum View Time is 10–120 seconds. Auto Release Time is normally 0 (off) and is used only for testing.

Review, accessed through F10, re-examines images after the original decision for authorised quality assurance and investigation. The Database Editor is available only in Review mode.

Overview, accessed through F11, allows authorised quality-control personnel to observe a connected Viewer’s live work.

The Movement Log records and replays mode changes, zooms, pans, brightness and contrast adjustments. It makes the examination and decision traceable.

Key takeaway: Keep roles separate, configuration controlled and the examination accountable.

## state-01 — existing narration retained

Panel 1: The Viewer. The Viewer: Examines each live image; Uses the image-enhancement tools; Compares reference images; Annotates and comments where appropriate; Makes the release-or-hold decision. The Viewer does not configure the viewing station. 

Key takeaway: The Viewer examines and decides—but does not control configuration. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-02 — existing narration retained

Panel 2: The Supervisor. Only the Supervisor may configure a viewing station. Configuration includes: IVServer IP address; Viewer ID; Minimum View Time; Auto Release Time; Saved default palette, invert, zoom and function settings. Viewer IDs are: 1–4: Normal Scannex Viewers; 9–16: Review and Overview stations. Minimum View Time must be between 10 and 120 seconds. Auto Release Time is normally set to 0—off. It is used only for testing. 

Key takeaway: Configuration is a controlled supervisory privilege, not a Viewer function. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-03 — existing narration retained

Panel 3: Review — F10. A Reviewer logs in with a name and password to re-examine images after the original decision. Review supports: Quality assurance; Investigation of questionable decisions; Confirmation of correct viewing; Authorised image-database management. The Database Editor is available only in Review mode. 

Key takeaway: Review examines what happened after the original viewing session. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-04 — existing narration retained

Panel 4: Overview — F11. An Overviewer logs in and uses the Movement Log to select a connected Viewer. Overview allows authorised quality-control personnel to observe a Viewer’s live work and confirm that images are being examined properly. 

Key takeaway: Overview provides real-time quality assurance of connected Viewers. Why this matters: Use the viewing system methodically and make a documented, accountable decision.

## state-05 — existing narration retained

Panel 5: The Movement Log. The Movement Log records and replays the exact sequence of actions taken during the original examination, including: Mode changes; Zoom changes; Panning; Brightness adjustments; Contrast adjustments. This makes the decision process transparent, discourages careless viewing and protects a Viewer who follows the correct procedure. 

Key takeaway: The Movement Log shows not only the decision, but how the Viewer reached it. Why this matters: Use the viewing system methodically and make a documented, accountable decision.
